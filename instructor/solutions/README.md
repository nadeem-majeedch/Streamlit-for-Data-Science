## Solution Format

### Runnable Solutions (`*_solution.py`)
Complete, runnable Streamlit apps with:
- All TODO sections filled in
- Comments explaining each section
- Production-quality code
- Can be run with `streamlit run <solution_file>`

### Solution Notes (`*_notes.md`)
Markdown documents with:
- **Expected approach** — The recommended solution strategy
- **Key code** — Critical code snippets (not full app)
- **Alternative approaches** — Other valid solutions
- **Common mistakes** — What students typically get wrong
- **Grading notes** — How to award partial credit
- **Estimated time** — How long the exercise should take

### Assignment Solutions (`A*_solution_notes.md`)
Comprehensive guides with:
- **Architecture** — Recommended file structure
- **Key implementation** — Critical code for each task
- **Grading breakdown** — Per-task point allocation guidance
- **Common errors** — Typical student mistakes and point deductions
- **Sample screenshots** — What the app should look like

## How to Use These Solutions

### Before Grading
1. Run each solution yourself to verify it works
2. Review the common mistakes section
3. Note which tasks are most challenging

### During Grading
1. Compare student code against the expected approach
2. Award credit for alternative valid approaches
3. Use the grading notes for consistent point allocation
4. Note patterns in common mistakes for class feedback

### After Grading
1. Use common mistakes for class-wide feedback
2. Update solution notes if new valid approaches emerge
3. Note any ambiguities in exercise instructions
