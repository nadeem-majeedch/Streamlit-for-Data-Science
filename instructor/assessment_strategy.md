## Assessment Descriptions

### Weekly Quizzes (10%)
- **Format:** Online, 10–15 questions each
- **Duration:** 15 minutes
- **Types:** MCQ, true/false, short answer, code output
- **Timing:** Start of each lecture session
- **Policy:** Drop lowest 2 scores
- **Resources:** Closed-book (no notes)

### Lab Assessments (10%)
- **Format:** Supervised in-lab practical
- **Duration:** 50 minutes
- **Weight:** 30 marks each (Labs 1, 2, 3)
- **Tasks:** 3–4 progressive tasks + bonus
- **Assessment:** Working code + correctness + design

### Mid-Course Assessment (10%)
- **Format:** Written exam + practical component
- **Duration:** 2 hours
- **Weight:** 100 marks
- **Sections:**
  - Part A: Conceptual (30 marks) — explanations, comparisons, design
  - Part B: Coding (40 marks) — write Streamlit code from specification
  - Part C: Debugging (15 marks) — find and fix bugs in given code
  - Part D: Design (15 marks) — architecture and UI design decisions
- **Scope:** M01–M08 (Weeks 1–8)

### Practical Exam (10%)
- **Format:** Timed coding in lab environment
- **Duration:** 3 hours
- **Weight:** 100 marks
- **Tasks:** 4 independent tasks of increasing difficulty
- **Resources:** Official documentation allowed (no AI tools)
- **Scope:** M01–M10

### Assignments (20%)
| Assignment | Weight | Scope | Submission |
|------------|--------|-------|------------|
| A01 — Personal Dashboard | 4% | M01–M03 | GitHub repo + deployed app |
| A02 — Data Explorer | 4% | M04–M06 | GitHub repo + deployed app |
| A03 — Multipage App | 4% | M07–M10 | GitHub repo + deployed app |
| A04 — ML Production App | 8% | M11–M16 | GitHub repo + deployed app + tests |

**Submission:** Each assignment requires:
1. GitHub repository with clean commit history
2. Working code (verified by instructor)
3. Deployed app on Community Cloud (where applicable)
4. README with setup instructions

### Final Practical Assessment (15%)
- **Format:** Comprehensive hands-on exam
- **Duration:** 4 hours
- **Weight:** 150 marks
- **Tasks:** 7 tasks covering the full course
- **Scope:** All modules (M01–M16)

### Capstone Project (15%)
- **Format:** 3-week individual project
- **Weight:** 200 marks (capped at 215 with bonus)
- **Deliverables:**
  1. GitHub repository with full history
  2. Deployed application on Community Cloud
  3. Documentation (README, setup guide)
  4. 10-minute presentation with live demo
- **Detailed spec:** See `projects/final_capstone.md`

### Participation (5%)
- **Criteria:**
  - Regular attendance (min 80%)
  - Active contribution to discussions
  - Constructive peer feedback
  - Helping peers during labs
- **Assessment:** Self-report + instructor observation

### Pre/Post Assessment (5%)
- **Pre-course (2.5%):** Completed before Week 1
- **Post-course (2.5%):** Completed in Week 16
- **Grading:** Completion + growth measurement
- **Purpose:** Measure learning outcomes, not gate-keep

## Academic Integrity

### Allowed
- Using course materials and readings
- Referencing Stack Overflow and documentation
- Discussing general approaches with classmates
- Using AI tools for learning (not for submission)

### Not Allowed
- Copying code from other students
- Copying from AI tools (ChatGPT, Copilot) for submission
- Submitting work from previous semesters
- Deploying another student's app
- Sharing solutions during the semester

### Detection
- Code similarity analysis
- Git commit history review
- Deployed app verification
- Oral examination (may ask to explain code)

### Consequences
- First offense: 0 for the assessment + warning
- Second offense: F for the course
- All incidents reported to department
