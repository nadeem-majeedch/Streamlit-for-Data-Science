# 📅 Course Plan

> **Streamlit for Data Science — Learn, Build, Deploy**
> *16-Week Semester Plan for University Instructors*

---

## Course Overview

| Field | Detail |
|-------|--------|
| **Course Title** | Streamlit for Data Science |
| **Duration** | 16 weeks |
| **Sessions per Week** | 2 (1 × 120 min lecture + 1 × 50 min lab) |
| **Total Contact Hours** | 48 hours (32 lecture + 16 lab) |
| **Self-Study Hours** | ~80 hours (readings, notebooks, projects) |
| **Prerequisites** | Python programming, basic Pandas/NumPy, intro statistics |

## Resource Requirements

### Software (Free)
- Python 3.9+
- Streamlit (latest stable)
- VS Code or similar IDE
- Git + GitHub account
- Streamlit Community Cloud account

### Python Packages
- Core: `streamlit`, `pandas`, `numpy`, `matplotlib`
- Visualization: `plotly`, `seaborn`
- ML: `scikit-learn`, `joblib`
- AI: `transformers` (optional), `openai` (optional)
- Database: `sqlite3` (built-in)
- Testing: `pytest`, `streamlit-testing`

### Hardware
- Any modern laptop/desktop (8GB RAM minimum)
- Internet connection for Community Cloud deployment

## Instructor Preparation Checklist

### Before Semester
- [ ] Run through all 20 exercises yourself
- [ ] Deploy one app to Community Cloud
- [ ] Prepare GitHub org or classroom for student repos
- [ ] Set up grading rubric templates
- [ ] Review all assessment materials

### Weekly
- [ ] Test live-coding examples night before lecture
- [ ] Review student quiz results from previous week
- [ ] Prepare discussion questions for the session
- [ ] Update common mistakes document if new patterns emerge

### After Mid-Course
- [ ] Review A01/A02 grades for struggling students
- [ ] Adjust pacing based on student feedback
- [ ] Prepare capstone project guidelines
