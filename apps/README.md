## Running Demo Apps

```bash
# Run any demo app
streamlit run apps/06_dashboard_demo.py

# Run on a different port
streamlit run apps/06_dashboard_demo.py --server.port 8502

# Run the modular multipage app
streamlit run apps/13_modular_app/app.py
```
