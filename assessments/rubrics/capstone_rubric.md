# Capstone Project Rubric

> **Streamlit for Data Science — Learn, Build, Deploy**  
> Grading rubric for the Capstone Project (P08).

---

## Assessment Criteria

| Criterion | Weight | Excellent (A) | Good (B) | Satisfactory (C) | Needs Work (D/F) |
|---|---|---|---|---|---|
| **Problem Definition & Design** | 15% | Clear problem statement, thorough design doc, justified tech choices | Good problem, adequate design | Vague problem, minimal design | No design document |
| **Functionality** | 25% | All features work, edge cases handled, graceful errors | Core features work, minor bugs | Some features broken | App does not run |
| **Architecture** | 15% | Clean separation of concerns, reusable components, proper state | Mostly clean, some mixing | Tangled code, hard to modify | Monolithic, no structure |
| **Data & ML/AI Integration** | 15% | Robust data pipeline, meaningful ML/AI integration | Functional pipeline, basic ML | Minimal data handling | No data integration |
| **Testing & Security** | 15% | Full AppTest suite, secrets managed, input validated | Basic tests, secrets in place | Partial tests, some gaps | No tests, secrets in source |
| **Deployment** | 10% | Deployed to Cloud, CI/CD pipeline, README complete | Deployed, basic README | Partially deployed | Not deployed |
| **Presentation** | 5% | Clear, confident, well-organized, handles Q&A | Good delivery, minor issues | Adequate but disorganized | Unprepared |

**Total: 100%**

## CLO Coverage

The capstone assesses all 12 Course Learning Outcomes (see [learning_outcomes.md](../../docs/learning_outcomes.md)):

- **CLO1–C2:** App fundamentals and interactivity
- **CLO3:** Visualization strategy
- **CLO4–C5:** State management and performance
- **CLO6:** Architecture decisions
- **CLO7:** Data source integration
- **CLO8–C9:** ML/AI components
- **CLO10:** Testing and security
- **CLO11:** Deployment and monitoring
- **CLO12:** Full development lifecycle
