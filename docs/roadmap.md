## 🚀 Project Ladder

Projects increase in scope and complexity across the semester.

```
P01 ──► P02 ──► P03 ──► P04 ──► P05 ──► P06 ──► P07 ──► P08
Beginner  Intermediate    Advanced      ML/AI      Deploy    CAPSTONE
Week 2    Week 4          Week 7        Week 10    Week 13   Week 14–16
```

| # | Project | Level | Weeks | Key Modules | Key Skills |
|---|---|---|---|---|---|
| [P01](../projects/p01_personal_dashboard/) | Personal Dashboard | Beginner | 2–3 | M01–M03 | `st.write`, widgets, layout, theming |
| [P02](../projects/p02_data_explorer/) | Data Explorer | Intermediate | 4–5 | M04–M05 | File upload, Pandas, charts, session state |
| [P03](../projects/p03_survey_tool/) | Form-Based Survey Tool | Intermediate | 5–6 | M05–M06 | Forms, validation, file handling |
| [P04](../projects/p04_realtime_dashboard/) | Real-Time Dashboard | Advanced | 7–8 | M07–M09 | Caching, fragments, `run_every`, multipage |
| [P05](../projects/p05_crud_app/) | CRUD Database App | Advanced | 10–11 | M09–M11 | SQL, forms, authentication |
| [P06](../projects/p06_ml_playground/) | ML Model Playground | ML | 12–13 | M12 | Model loading, inference, SHAP |
| [P07](../projects/p07_rag_chat/) | RAG Document Chat | AI/LLM | 13 | M13 | Chat UI, embeddings, vector store |
| [P08](../projects/p08_capstone/) | **Capstone Project** | Production | 14–16 | All | All skills + CI/CD + deployment |
