## 🚀 Project Ladder

Projects increase in scope and complexity across the semester.

```
P01 ──► P02 ──► P03 ──► P04 ──► P05 ──► P06 ──► P07 ──► P08
Beginner  Intermediate    Advanced      ML/AI      Deploy    CAPSTONE
Week 2    Week 4          Week 7        Week 10    Week 13   Week 14–16
```

| # | Project | Level | Weeks | Key Modules | Key Skills |
|---|---|---|---|---|---|
| [P01](../projects/P01_csv_data_viewer.md) | Personal Dashboard | Beginner | 2–3 | M01–M03 | `st.write`, widgets, layout, theming |
| [P02](../projects/P02_data_explorer.md) | Data Explorer | Intermediate | 4–5 | M04–M05 | File upload, Pandas, charts, session state |

| [P04](../projects/P02_data_explorer.md) | Real-Time Dashboard | Advanced | 7–8 | M07–M09 | Caching, fragments, `run_every`, multipage |
| [P05](../projects/P14_database_dashboard.md) | CRUD Database App | Advanced | 10–11 | M09–M11 | SQL, forms, authentication |
| [P06](../projects/P06_ml_model_playground.md) | ML Model Playground | ML | 12–13 | M12 | Model loading, inference, SHAP |
| [P07](../projects/P07_rag_document_chat.md) | RAG Document Chat | AI/LLM | 13 | M13 | Chat UI, embeddings, vector store |
| [P08](../projects/final_capstone.md) | **Capstone Project** | Production | 14–16 | All | All skills + CI/CD + deployment |
