## How to Read This Matrix

Each CLO follows the chain:

```
TAUGHT (Reading + Notebook) → PRACTICED (Exercise) → ASSESSED (Quiz + Exam) → APPLIED (Assignment + Project)
```

A **complete chain** means the CLO is fully covered. Gaps are flagged with ⚠️.

### ⚠️ Minor Gaps (0/12)

All CLOs have complete TAUGHT → PRACTICED → ASSESSED → APPLIED chains. See individual CLO details above for resource listings.

### Topics Taught But Not Formally Assessed

| Topic | Taught In | Assessment Gap |
|-------|-----------|---------------|
| `st.fragment` (partial reruns) | M07 reading + notebook | Covered in Q08 but no hands-on exam question |
| Custom Streamlit components | M11 reading | No exercise or quiz — only mentioned |
| MLOps integration (MLflow, DVC) | M16 reading | Mentioned but not exercised |
| NoSQL databases | M10 reading | Mentioned but not exercised |

**Recommendation:** These are acceptable as "awareness" topics. Custom components and MLOps are advanced topics better suited for the capstone extension. NoSQL is mentioned for context. No action required unless the instructor wants deeper coverage.

### Assessments Without Adequate Preparation

| Assessment | Preparation Gap |
|------------|----------------|
| Midcourse §Part D (Design) | Students may lack practice with architecture design questions — Lab 3 helps but is hands-on, not written |
| Practical Exam (3 hours) | No timed practice exam provided — students may be unfamiliar with time pressure |

**Recommendation:** Provide sample practical exam questions in instructor materials. The question_bank.md contains practice questions that can help.

### Projects Requiring Skills Not Explicitly Taught

| Project | Skill Required | Status |
|---------|---------------|--------|
| P15 NLP Application | TF-IDF, text classification | ✅ Taught in M13 |
| P16 LLM Chat | Chat UI, API integration | ✅ Taught in M13 |
| P17 Document Q&A | RAG, embeddings, vector stores | ✅ Taught in M14 (R18 + N18 + E18) |
| P20 Complete Deployed App | All skills | ✅ Capstone integrates everything |

All project skills are covered by the curriculum. P17 is the most ambitious — instructor should provide a RAG starter template.

### Excessive Repetition

| Area | Observation |
|------|-------------|
| Session state | Covered in M05 (reading + notebook + exercise + quiz) AND M07 (caching exercise also uses state). This is **intentional** — state is the hardest concept and benefits from reinforcement. |
| `st.cache_data` vs `st.cache_resource` | Taught in M07 reading, practiced in E12, assessed in Q08, applied in A02/A03. **Appropriate repetition** for a core concept. |
| File upload | Covered in M06 (reading + notebook + exercise + quiz). No redundant coverage elsewhere. |

**Conclusion:** No excessive repetition detected. Key concepts are reinforced appropriately across modules.
